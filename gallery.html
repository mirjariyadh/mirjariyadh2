This page reads your folder through a tiny script that runs under your own Google account — no API key, no Cloud project, no billing. One-time setup, about 2 minutes:

  1. Go to script.google.com → New project.
  2. Delete the placeholder code, paste in the script below, then click Deploy → New deployment.
  3. Type: Web app. Execute as: Me. Who has access: Anyone. Click Deploy, and approve the permission prompt (it's your own script asking to read your own Drive).
  4. Copy the Web app URL it gives you and paste it into the field above.
